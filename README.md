1. ROCK PAPER SCISSOR  GAME
I made this project as a hackclub project its a classic rock, paper, scissors game built using  Python language.  this as a fun to play and terminal based project to focus on  logic, uses input of user in number for the rock , paper and scissor as number are more useful than writing whole words which helps in creating a fun, interactive experience, its a fun game. built in python and it took around 2-2:30 h

like who  wants to write rock , paper , scissor everytime


-->> Why did i built this
I wanted to challenge myself to write clean , logical and fun to play  game that feels easy and responsive. Instead of just a simple script, I focus on making the user experience inetractive. the game is easy to understand and handles input errors in a good manner.

--> Key Features
1.  fair Gameplay: it uses random module so that if u have a fair chances of winning , even with a computer.
2. Number Input - u  can input rock , paper and scisor using 0,1,2 for each 
3. Portable- it cann be used as a  .exe so you can play without installing Python. 

--> Tech Stack
Language: Python -> ( mentioned earlier but yeah)
Packaging-> PyInstaller ( for easy installation), btw i had to give 20 min extra to learn this

You don't need Python installed to play!

1.. Download RROCK PAPER SCISSOR.exe

2.. Double-click the file and enjoy the game!
